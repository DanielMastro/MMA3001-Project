create_zenodo_input_data

create_zenodo_input_data.py - turn the open Zenodo IPM maps into a winding table.

Where this fits in the project

The project's script is developed on the Cobalt FEA and validated, unchanged, on a second, independent motor. That motor's data comes from Zenodo as dq maps (Psi_d.csv, Psi_q.csv, Torque.csv), not in the Maxwell winding-table format the script reads. This file rebuilds the Maxwell columns from the dq maps and writes

Input_Data/Zenodo_IPM/zenodo_input_data.csv                   same columns as cobalt_input_data.csv
Input_Data/Zenodo_IPM/zenodo_input_data_operating_points.csv  FEA torque per operating point
Input_Data/Zenodo_IPM/zenodo_input_data_provenance.json       how every column was made

so preprocess.py can read both motors the same way. run_all.py calls it automatically if zenodo_input_data.csv is missing.

Source dataset (CC BY 4.0): Mai, Liu, Wagner, Hofmann, "Current Harmonics Minimization of PMSM Based on Iterative Learning Control and Neural Networks: Motor Data", Zenodo (2023), https://doi.org/10.5281/zenodo.7866449 Cite the associated paper when using the data (the dataset asks for this): Machines 2023, 11(8), 784, https://doi.org/10.3390/machines11080784

Source layout: three CSVs (Psi_d, Psi_q, Torque). Each has a time column plus 2331 operating-point columns named "... - Gamma='' im='A'". Each column is one electrical rotation (61 samples, both endpoints included). Im is the peak phase current, 0-620 A in 10 A steps. Gamma is the current angle, -180..180 deg in 10 deg steps: Gamma = 0 is pure +q and Gamma = +90 is pure -d, so Id = -Imsin(Gamma) and Iq = Imcos(Gamma). This is the same convention as TimingAdjustment in the Maxwell winding table. The dq quantities are amplitude-invariant (peak): the FEA torque matches 1.5p(psi_diq - psi_qid) with p = 8 to ~0.05 Nm RMS.

How each output column is produced (also written to a provenance JSON): J [A_per_m2] PROXY. Im / conductor_area. The conductor area is not in the dataset, so the default area of 1 m^2 makes J numerically equal to Im [A]. J is exactly 0 at no load, which the analysis script uses to find no-load blocks. NStepsPerElectricalCycle [] Samples per block minus one (60). RPM [rpm] Derived from the time span of one electrical rotation and the pole pairs. TimingAdjustment [deg] = Gamma (same convention). Time [s] From the source time column (resets each block). L(Phase_x,Phase_y) [uH]/[nH] DERIVED (the dataset has no inductance matrix). Incremental inductance dpsi_abc/di_abc at each rotor position: finite differences of psi_d, psi_q across the (Im, Gamma) grid give the dq matrix [[Ldd, Ldq], [Lqd, Lqq]]. The cross terms are symmetrised (reciprocity), then mapped to abc with the inverse Park transform. Zero-sequence inductance is set to 0 (not in the data; it does not affect Ld or Lq). These are NOT Maxwell's frozen-permeability values, so for this motor the "matrix" and "incremental" inductances in the analysis script agree by construction. Use --inductance none to leave the columns empty. FluxLinkage(Phase_x) [Wb] RECONSTRUCTED by inverse Park transform of psi_d, psi_q (zero-sequence flux assumed 0). InducedVoltage(Phase_x) [uv] DERIVED as d(psi_x)/dt by periodic central differences (Maxwell reports +dpsi/dt). InputCurrent(Phase_x) [mA] RECONSTRUCTED by inverse Park transform of the constant (Id, Iq) of each operating point.

When analysing the output with the winding-table script, use turns_ratio = 1, stack_factor = 1, pole_pairs = 8. The data is already for the full machine. Your own motor's 33/2 and 0.9 corrections do not apply.

130def park(a, b, c, theta):
131    """Park-transform a three-phase quantity (abc -> dq), amplitude-invariant.
132
133    The same transform as preprocess.park_vec(), without the zero-sequence
134    term.
135
136    Parameters
137    ----------
138    a : array_like
139        Phase A values.
140    b : array_like
141        Phase B values.
142    c : array_like
143        Phase C values.
144    theta : array_like
145        Rotor electrical angle [rad].
146
147    Returns
148    -------
149    d : numpy.ndarray
150        d-axis component.
151    q : numpy.ndarray
152        q-axis component.
153    """
154    d = (2 / 3) * (a * np.cos(theta) + b * np.cos(theta - 2 * np.pi / 3)
155                   + c * np.cos(theta + 2 * np.pi / 3))
156    q = -(2 / 3) * (a * np.sin(theta) + b * np.sin(theta - 2 * np.pi / 3)
157                    + c * np.sin(theta + 2 * np.pi / 3))
158    return d, q

161def inverse_park(d, q, theta):
162    """Inverse Park transform (dq -> abc), amplitude-invariant.
163
164    The zero-sequence component is taken as 0. The exact inverse of park().
165
166    Parameters
167    ----------
168    d : array_like
169        d-axis component.
170    q : array_like
171        q-axis component.
172    theta : array_like
173        Rotor electrical angle [rad].
174
175    Returns
176    -------
177    a : numpy.ndarray
178        Phase A values.
179    b : numpy.ndarray
180        Phase B values.
181    c : numpy.ndarray
182        Phase C values.
183    """
184    a = d * np.cos(theta) - q * np.sin(theta)
185    b = d * np.cos(theta - 2 * np.pi / 3) - q * np.sin(theta - 2 * np.pi / 3)
186    c = d * np.cos(theta + 2 * np.pi / 3) - q * np.sin(theta + 2 * np.pi / 3)
187    return a, b, c

190def incremental_inductance_dq(im_vals, gamma_deg, psi_d, psi_q):
191    """Compute incremental dq inductances from flux maps on a polar current grid.
192
193    Parameters
194    ----------
195    im_vals : numpy.ndarray
196        Current magnitudes [A], shape (n_im,), ascending and starting at 0.
197    gamma_deg : numpy.ndarray
198        Current angles [deg], shape (n_g,), uniformly spaced over a full
199        circle WITHOUT the duplicate endpoint (e.g. -180..170 in 10 deg steps).
200    psi_d : numpy.ndarray
201        d-axis flux linkage [Wb], shape (n_t, n_im, n_g): one map per rotor
202        sample.
203    psi_q : numpy.ndarray
204        q-axis flux linkage [Wb], the same shape.
205
206    Returns
207    -------
208    Ldd : numpy.ndarray
209        dpsi_d/dId [H], shape (n_t, n_im, n_g).
210    Ldq : numpy.ndarray
211        dpsi_d/dIq [H], the same shape.
212    Lqd : numpy.ndarray
213        dpsi_q/dId [H], the same shape.
214    Lqq : numpy.ndarray
215        dpsi_q/dIq [H], the same shape.
216
217    Raises
218    ------
219    ValueError
220        If im_vals does not start at 0, or gamma_deg is not uniformly spaced
221        over a full circle.
222
223    Notes
224    -----
225    Derivatives along the grid axes (np.gradient in Im, 2nd order; periodic
226    4th-order central differences in Gamma) are converted to d/dId and d/dIq
227    with the exact Jacobian of Id = -Im sin(g), Iq = Im cos(g):
228
229        d/dId = -sin(g) d/dIm - cos(g)/Im d/dg
230        d/dIq =  cos(g) d/dIm - sin(g)/Im d/dg
231
232    At Im = 0 the polar Jacobian is singular, so Cartesian central
233    differences across the first ring are used (+-Id at g = -/+90 deg, +-Iq
234    at g = 0/180).
235    """
236    if im_vals[0] != 0:
237        raise ValueError("Inductance derivation needs an Im = 0 point")
238    dg_deg = np.diff(gamma_deg)
239    if not np.allclose(dg_deg, dg_deg[0]) or not np.isclose(dg_deg[0] * len(gamma_deg), 360):
240        raise ValueError("Gamma must be uniformly spaced over a full circle (no duplicate endpoint)")
241    g = np.deg2rad(gamma_deg)[None, None, :]
242    dg = np.deg2rad(dg_deg[0])
243    s, c = np.sin(g), np.cos(g)
244    I = im_vals[None, :, None].astype(float)
245
246    def to_dq(x):
247        x_im = np.gradient(x, im_vals, axis=1, edge_order=2)
248        # 4th-order periodic central difference in Gamma. The 2nd-order stencil
249        # underestimates the angular derivative by sin(h)/h (~0.5 % at 10 deg).
250        r = lambda k: np.roll(x, -k, axis=2)
251        x_g = (-r(2) + 8 * r(1) - 8 * r(-1) + r(-2)) / (12 * dg)
252        with np.errstate(divide="ignore", invalid="ignore"):
253            return -s * x_im - c / I * x_g, c * x_im - s / I * x_g
254
255    Ldd, Ldq = to_dq(psi_d)
256    Lqd, Lqq = to_dq(psi_q)
257
258    # Origin: Cartesian central differences on the first ring
259    r = im_vals[1]
260    k = lambda deg: int(np.argmin(np.abs((gamma_deg - deg + 180) % 360 - 180)))
261    pd_, md_, pq_, mq_ = k(-90), k(90), k(0), k(180)     # +Id, -Id, +Iq, -Iq
262    for L_id, L_iq, psi in ((Ldd, Ldq, psi_d), (Lqd, Lqq, psi_q)):
263        L_id[:, 0, :] = ((psi[:, 1, pd_] - psi[:, 1, md_]) / (2 * r))[:, None]
264        L_iq[:, 0, :] = ((psi[:, 1, pq_] - psi[:, 1, mq_]) / (2 * r))[:, None]
265    return Ldd, Ldq, Lqd, Lqq

268def dq_to_abc_inductance(Ldd, Lqq, Lc, theta):
269    """Build the 3x3 phase inductance matrix from a symmetric dq matrix.
270
271    The dq matrix is [[Ldd, Lc], [Lc, Lqq]] with zero-sequence inductance 0
272    (amplitude-invariant transform). Park-transforming the result
273    (T @ L @ inv(T)) returns Ldd, Lqq and Lc exactly.
274
275    Parameters
276    ----------
277    Ldd : numpy.ndarray
278        d-axis incremental inductance [H].
279    Lqq : numpy.ndarray
280        q-axis incremental inductance [H].
281    Lc : numpy.ndarray
282        Symmetrised cross-coupling inductance [H].
283    theta : numpy.ndarray
284        Rotor electrical angle [rad], broadcastable with the inductances.
285
286    Returns
287    -------
288    L_abc : dict of numpy.ndarray
289        Phase inductances [H] keyed by phase pair, e.g. ("A", "B").
290
291    Notes
292    -----
293    L_xy = 2/3 * (Ldd cos(tx) cos(ty) + Lqq sin(tx) sin(ty) - Lc sin(tx + ty)),
294    with tx = theta, theta - 2pi/3 and theta + 2pi/3 for phases A, B and C.
295    """
296    tx = {"A": theta, "B": theta - 2 * np.pi / 3, "C": theta + 2 * np.pi / 3}
297    out = {}
298    for x in "ABC":
299        for y in "ABC":
300            out[(x, y)] = (2 / 3) * (Ldd * np.cos(tx[x]) * np.cos(tx[y])
301                                     + Lqq * np.sin(tx[x]) * np.sin(tx[y])
302                                     - Lc * np.sin(tx[x] + tx[y]))
303    return out

309def read_zenodo_map(path: Path):
310    """Read one Zenodo map CSV (Psi_d, Psi_q or Torque).
311
312    Parameters
313    ----------
314    path : pathlib.Path
315        The CSV: a time column, then one column per operating point named
316        `... Gamma='<deg>' im='<A>A'`.
317
318    Returns
319    -------
320    time : numpy.ndarray
321        Sample times, shape (n_t,), in the file's time unit.
322    time_unit : str
323        Unit parsed from the time column header, e.g. "ms".
324    gamma_deg : numpy.ndarray
325        Current angle of each operating point [deg], shape (n_op,).
326    im_a : numpy.ndarray
327        Peak current magnitude of each operating point [A], shape (n_op,).
328    values : numpy.ndarray
329        The map values, shape (n_t, n_op).
330
331    Raises
332    ------
333    ValueError
334        If the first column is not time, a column header cannot be parsed,
335        or the values contain NaN.
336    """
337    df = pd.read_csv(path)
338    tcol = df.columns[0]
339    if not tcol.lower().startswith("time"):
340        raise ValueError(f"{path.name}: first column should be time, got '{tcol}'")
341    m_unit = re.search(r"\[(\w+)\]", tcol)
342    time_unit = m_unit.group(1) if m_unit else "s"
343
344    meta = []
345    for col in df.columns[1:]:
346        m = _HEADER_RE.search(col)
347        if m is None:
348            raise ValueError(f"{path.name}: cannot parse Gamma/Im from column '{col}'")
349        meta.append((float(m.group(1)), float(m.group(2))))
350    meta = np.array(meta)
351
352    values = df.iloc[:, 1:].to_numpy(dtype=float)
353    if np.isnan(values).any():
354        raise ValueError(f"{path.name}: contains NaN values")
355    return df[tcol].to_numpy(dtype=float), time_unit, meta[:, 0], meta[:, 1], values

358def load_zenodo(psi_d_path: Path, psi_q_path: Path, torque_path: Path | None):
359    """Load the Zenodo CSVs and check that they belong together.
360
361    Parameters
362    ----------
363    psi_d_path : pathlib.Path
364        Psi_d.csv.
365    psi_q_path : pathlib.Path
366        Psi_q.csv.
367    torque_path : pathlib.Path or None
368        Torque.csv, or None to skip the torque.
369
370    Returns
371    -------
372    z : dict
373        "time", "time_unit", "gamma", "im", "psi_d", "psi_q" and "torque"
374        (None without a torque file), as read by read_zenodo_map().
375
376    Raises
377    ------
378    ValueError
379        If the files do not share the same time base and operating points,
380        the time samples are not uniformly spaced, or there is no Im = 0
381        (no-load) point.
382    """
383    t, unit, g, im, psi_d = read_zenodo_map(psi_d_path)
384    t2, _, g2, im2, psi_q = read_zenodo_map(psi_q_path)
385    if not (np.allclose(t, t2) and np.array_equal(g, g2) and np.array_equal(im, im2)):
386        raise ValueError("Psi_d and Psi_q files do not share the same time base / operating points")
387
388    torque = None
389    if torque_path is not None:
390        t3, _, g3, im3, torque = read_zenodo_map(torque_path)
391        if not (np.allclose(t, t3) and np.array_equal(g, g3) and np.array_equal(im, im3)):
392            raise ValueError("Torque file does not match the flux files")
393
394    dt = np.diff(t)
395    if not np.allclose(dt, dt[0], rtol=1e-6):
396        raise ValueError("Time samples are not uniformly spaced")
397    if not np.any(im == 0):
398        raise ValueError("No Im = 0 (no-load) operating points: the analysis script needs them")
399    return dict(time=t, time_unit=unit, gamma=g, im=im, psi_d=psi_d, psi_q=psi_q, torque=torque)

405def _inductance_columns(im, g, psi_d, psi_q, theta):
406    """Fill the nine L(...) columns with the derived incremental inductance matrix.
407
408    Parameters
409    ----------
410    im : numpy.ndarray
411        Current magnitude of each operating point [A], shape (n_op,), sorted
412        Im outer and Gamma inner over a complete grid.
413    g : numpy.ndarray
414        Current angle of each operating point [deg], shape (n_op,).
415    psi_d : numpy.ndarray
416        d-axis flux linkage [Wb], shape (n_t, n_op).
417    psi_q : numpy.ndarray
418        q-axis flux linkage [Wb], shape (n_t, n_op).
419    theta : numpy.ndarray
420        Rotor electrical angle [rad], shape (n_t, 1).
421
422    Returns
423    -------
424    cols : dict of numpy.ndarray
425        Column name -> (n_t, n_op) values in that column's unit (uH or nH).
426    stats : dict of float
427        Inductance ranges and the reciprocity error |Ldq - Lqd|.
428    dq : tuple of numpy.ndarray
429        (Ldd, Lqq, Lc) [H], each of shape (n_t, n_op).
430
431    Raises
432    ------
433    ValueError
434        If the operating points do not form a complete Im x Gamma grid.
435    """
436    im_vals, g_vals = np.unique(im), np.unique(g)
437    if len(im_vals) * len(g_vals) != len(im):
438        raise ValueError("Operating points do not form a complete Im x Gamma grid")
439    n_t = psi_d.shape[0]
440    grid = lambda x: x.reshape(n_t, len(im_vals), len(g_vals))
441    # drop the duplicate +180 deg column for the periodic derivative, map it back afterwards
442    dup = np.isclose(g_vals[-1] - g_vals[0], 360)
443    g_red = g_vals[:-1] if dup else g_vals
444    n_red = len(g_red)
445    Ldd, Ldq, Lqd, Lqq = incremental_inductance_dq(
446        im_vals, g_red, grid(psi_d)[:, :, :n_red], grid(psi_q)[:, :, :n_red])
447    back = np.array([int(np.argmin(np.abs((g_red - gg + 180) % 360 - 180))) for gg in g_vals])
448    full = lambda L: L[:, :, back].reshape(n_t, -1)
449    Ldd, Ldq, Lqd, Lqq = full(Ldd), full(Ldq), full(Lqd), full(Lqq)
450
451    Lc = 0.5 * (Ldq + Lqd)                       # reciprocity: dpsi_d/diq = dpsi_q/did
452    asym = np.abs(Ldq - Lqd)
453    stats = {
454        "Ld_incremental_uH_range": [float(Ldd.min() * 1e6), float(Ldd.max() * 1e6)],
455        "Lq_incremental_uH_range": [float(Lqq.min() * 1e6), float(Lqq.max() * 1e6)],
456        "Ldq_cross_uH_range": [float(Lc.min() * 1e6), float(Lc.max() * 1e6)],
457        "reciprocity_|Ldq-Lqd|_median_uH": float(np.median(asym) * 1e6),
458        "reciprocity_|Ldq-Lqd|_p95_uH": float(np.percentile(asym, 95) * 1e6),
459    }
460
461    Labc = dq_to_abc_inductance(Ldd, Lqq, Lc, theta)
462    cols = {}
463    for col in WINDING_TABLE_COLUMNS:
464        m = re.match(r"L\(Phase_([ABC]),Phase_([ABC])\) \[(uH|nH)\]", col)
465        if m:
466            scale = 1e6 if m.group(3) == "uH" else 1e9
467            cols[col] = Labc[(m.group(1), m.group(2))] * scale
468    return cols, stats, (Ldd, Lqq, Lc)

471def build_winding_table(z: dict, pole_pairs: int, conductor_area_m2: float,
472                        time_unit: str | None = None, inductance: str = "incremental"):
473    """Build the Maxwell winding-table columns from the Zenodo maps.
474
475    Each operating point becomes one block of n_t rows (one electrical
476    rotation), ordered J (current) outer and TimingAdjustment (angle) inner,
477    as in the Maxwell export.
478
479    Parameters
480    ----------
481    z : dict
482        Output of load_zenodo().
483    pole_pairs : int
484        Number of pole pairs (8 for the Zenodo motor).
485    conductor_area_m2 : float
486        Conductor area for the J proxy, J = Im / area [m^2].
487    time_unit : str, optional
488        Override the time unit in the file header ("s", "ms" or "us").
489        Default None (use the header).
490    inductance : {"incremental", "none"}, optional
491        "incremental" (default) fills the L(...) columns with the derived
492        incremental matrix; "none" leaves them empty (NaN).
493
494    Returns
495    -------
496    table : pandas.DataFrame
497        The winding table, with the columns in WINDING_TABLE_COLUMNS order.
498    summary : pandas.DataFrame
499        One row per operating point: J, TimingAdjustment, Im, Gamma, Id, Iq,
500        the cycle-mean psi_d and psi_q, and when available the FEA torque,
501        its ripple and the dq inductances.
502    info : dict
503        rpm, period_s, n_t, n_op, time_unit, inductance and
504        inductance_stats.
505
506    Raises
507    ------
508    ValueError
509        If the time unit or the inductance option is unknown.
510    """
511    unit = time_unit or z["time_unit"]
512    if unit not in _TIME_UNITS:
513        raise ValueError(f"Unknown time unit '{unit}'")
514    t_s = (z["time"] - z["time"][0]) * _TIME_UNITS[unit]   # seconds from block start
515    n_t = len(t_s)
516    period_s = t_s[-1]                                      # one electrical rotation
517    theta = (2 * np.pi * t_s / period_s)[:, None]           # rotor electrical angle, (n_t, 1)
518    rpm = 60.0 / (period_s * pole_pairs)
519
520    # Sort operating points: current magnitude outer, angle inner
521    order = np.lexsort((z["gamma"], z["im"]))
522    g, im = z["gamma"][order], z["im"][order]
523    psi_d, psi_q = z["psi_d"][:, order], z["psi_q"][:, order]
524
525    gr = np.deg2rad(g)
526    i_d, i_q = -im * np.sin(gr), im * np.cos(gr)            # peak, amplitude-invariant
527
528    # Phase currents and flux linkages, shape (n_t, n_op)
529    ia, ib, ic = inverse_park(i_d[None, :], i_q[None, :], theta)
530    fa, fb, fc = inverse_park(psi_d, psi_q, theta)
531
532    # Induced voltage e = d(psi)/dt, periodic central differences over the
533    # n_t-1 unique samples (first and last sample are the same rotor angle)
534    dt = t_s[1] - t_s[0]
535
536    def ddt(f):
537        u = f[:-1]
538        e = (np.roll(u, -1, axis=0) - np.roll(u, 1, axis=0)) / (2 * dt)
539        return np.vstack([e, e[:1]])
540
541    ea, eb, ec = ddt(fa), ddt(fb), ddt(fc)
542
543    n_op = len(g)
544    flat = lambda x: np.asarray(x).T.reshape(-1)            # block-major (op, time)
545    rep = lambda v: np.repeat(v, n_t)
546
547    out = pd.DataFrame({
548        "J [A_per_m2]": rep(im / conductor_area_m2),
549        "NStepsPerElectricalCycle []": n_t - 1,
550        "RPM [rpm]": rpm,
551        "TimingAdjustment [deg]": rep(g),
552        "Time [s]": np.tile(t_s, n_op),
553    })
554    ind_stats, ind_dq = {}, None
555    if inductance == "incremental":
556        ind_cols, ind_stats, ind_dq = _inductance_columns(im, g, psi_d, psi_q, theta)
557        for col, val in ind_cols.items():
558            out[col] = flat(val)
559    elif inductance == "none":
560        for col in WINDING_TABLE_COLUMNS:
561            if col.startswith("L("):
562                out[col] = np.nan
563    else:
564        raise ValueError(f"Unknown inductance option '{inductance}'")
565    out["FluxLinkage(Phase_A) [Wb]"] = flat(fa)
566    out["FluxLinkage(Phase_B) [Wb]"] = flat(fb)
567    out["FluxLinkage(Phase_C) [Wb]"] = flat(fc)
568    out["InducedVoltage(Phase_A) [uv]"] = flat(ea) * 1e6
569    out["InducedVoltage(Phase_B) [uv]"] = flat(eb) * 1e6
570    out["InducedVoltage(Phase_C) [uv]"] = flat(ec) * 1e6
571    out["InputCurrent(Phase_A) [mA]"] = flat(ia) * 1e3
572    out["InputCurrent(Phase_B) [mA]"] = flat(ib) * 1e3
573    out["InputCurrent(Phase_C) [mA]"] = flat(ic) * 1e3
574    out = out[WINDING_TABLE_COLUMNS]
575
576    # Operating-point summary (one row per block), incl. FEA torque if available
577    keep = slice(0, n_t - 1)                                 # one full cycle, no duplicate endpoint
578    summary = pd.DataFrame({
579        "J [A_per_m2]": im / conductor_area_m2,
580        "TimingAdjustment [deg]": g,
581        "Im_A": im,
582        "Gamma_deg": g,
583        "Id_A": i_d,
584        "Iq_A": i_q,
585        "Psi_d_Wb": psi_d[keep].mean(axis=0),
586        "Psi_q_Wb": psi_q[keep].mean(axis=0),
587    })
588    if z["torque"] is not None:
589        tq = z["torque"][:, order]
590        summary["Torque_FEA_Nm"] = tq[keep].mean(axis=0)
591        summary["Torque_ripple_pkpk_Nm"] = np.ptp(tq[keep], axis=0)
592    if ind_dq is not None:
593        Ldd, Lqq, Lc = ind_dq
594        summary["Ld_inc_uH"] = Ldd[keep].mean(axis=0) * 1e6
595        summary["Lq_inc_uH"] = Lqq[keep].mean(axis=0) * 1e6
596        summary["Ldq_inc_uH"] = Lc[keep].mean(axis=0) * 1e6
597    return out, summary, dict(rpm=rpm, period_s=period_s, n_t=n_t, n_op=n_op, time_unit=unit,
598                              inductance=inductance, inductance_stats=ind_stats)

601def self_check(table: pd.DataFrame, summary: pd.DataFrame, n_t: int, pole_pairs: int):
602    """Check the conversion by transforming the written columns back to dq.
603
604    Park-transforms the abc flux, current and (if present) inductance
605    columns and compares them with the source values. Also compares the
606    flux-formula torque with the FEA torque.
607
608    Parameters
609    ----------
610    table : pandas.DataFrame
611        The winding table from build_winding_table().
612    summary : pandas.DataFrame
613        The operating-point summary from build_winding_table().
614    n_t : int
615        Samples per block.
616    pole_pairs : int
617        Number of pole pairs.
618
619    Returns
620    -------
621    checks : dict of float
622        The largest errors: max_err_psi_d_Wb, max_err_psi_q_Wb, max_err_id_A
623        and max_err_iq_A; when available, max_err_Ld_from_matrix_uH,
624        max_err_Lq_from_matrix_uH, torque_flux_vs_FEA_rms_Nm and
625        torque_FEA_max_Nm.
626    """
627    th = np.tile(2 * np.pi * np.arange(n_t) / (n_t - 1), len(summary))
628    d_f, q_f = park(table["FluxLinkage(Phase_A) [Wb]"].to_numpy(),
629                    table["FluxLinkage(Phase_B) [Wb]"].to_numpy(),
630                    table["FluxLinkage(Phase_C) [Wb]"].to_numpy(), th)
631    d_i, q_i = park(table["InputCurrent(Phase_A) [mA]"].to_numpy() * 1e-3,
632                    table["InputCurrent(Phase_B) [mA]"].to_numpy() * 1e-3,
633                    table["InputCurrent(Phase_C) [mA]"].to_numpy() * 1e-3, th)
634    blk = lambda x: x.reshape(-1, n_t)[:, :-1].mean(axis=1)
635    res = {
636        "max_err_psi_d_Wb": float(np.max(np.abs(blk(d_f) - summary["Psi_d_Wb"]))),
637        "max_err_psi_q_Wb": float(np.max(np.abs(blk(q_f) - summary["Psi_q_Wb"]))),
638        "max_err_id_A": float(np.max(np.abs(blk(d_i) - summary["Id_A"]))),
639        "max_err_iq_A": float(np.max(np.abs(blk(q_i) - summary["Iq_A"]))),
640    }
641    if "Ld_inc_uH" in summary:
642        # Park-transform the written 3x3 matrices (T @ L @ inv(T), as the analysis
643        # script does) and compare with the dq inductances they were built from
644        n = len(table)
645        c0, c1, c2 = np.cos(th), np.cos(th - 2 * np.pi / 3), np.cos(th + 2 * np.pi / 3)
646        s0, s1, s2 = np.sin(th), np.sin(th - 2 * np.pi / 3), np.sin(th + 2 * np.pi / 3)
647        T = (2 / 3) * np.stack([np.stack([c0, c1, c2], -1),
648                                np.stack([-s0, -s1, -s2], -1),
649                                np.full((n, 3), 0.5)], 1)
650        u, nn = 1e-6, 1e-9
651        col = lambda x, y, unit: table[f"L(Phase_{x},Phase_{y}) [{unit}]"].to_numpy()
652        L = np.empty((n, 3, 3))
653        for i, x in enumerate("ABC"):
654            for j, y in enumerate("ABC"):
655                L[:, i, j] = col(x, y, "uH") * u if x == y else col(x, y, "nH") * nn
656        D = T @ L @ np.linalg.inv(T)
657        res["max_err_Ld_from_matrix_uH"] = float(np.max(np.abs(blk(D[:, 0, 0]) * 1e6 - summary["Ld_inc_uH"])))
658        res["max_err_Lq_from_matrix_uH"] = float(np.max(np.abs(blk(D[:, 1, 1]) * 1e6 - summary["Lq_inc_uH"])))
659    if "Torque_FEA_Nm" in summary:
660        t_flux = 1.5 * pole_pairs * (summary["Psi_d_Wb"] * summary["Iq_A"]
661                                     - summary["Psi_q_Wb"] * summary["Id_A"])
662        err = t_flux - summary["Torque_FEA_Nm"]
663        res["torque_flux_vs_FEA_rms_Nm"] = float(np.sqrt(np.mean(err ** 2)))
664        res["torque_FEA_max_Nm"] = float(summary["Torque_FEA_Nm"].max())
665    return res

733def create_zenodo_input_data(psi_d_path, psi_q_path, torque_path, out_path,
734                             pole_pairs=POLE_PAIRS_DEFAULT, conductor_area=1.0,
735                             time_unit=None, inductance="incremental", verbose=True):
736    """Convert the Zenodo CSVs and write the three output files.
737
738    Writes the winding table to out_path and two files beside it, named
739    after it: `..._operating_points.csv` (the FEA torque per operating point)
740    and `..._provenance.json` (how every column was made).
741
742    Parameters
743    ----------
744    psi_d_path : str or pathlib.Path
745        Zenodo Psi_d.csv.
746    psi_q_path : str or pathlib.Path
747        Zenodo Psi_q.csv.
748    torque_path : str or pathlib.Path or None
749        Zenodo Torque.csv, or None to skip the FEA torque. A path that does
750        not exist is skipped with a note.
751    out_path : str or pathlib.Path
752        The winding table to write (zenodo_input_data.csv).
753    pole_pairs : int, optional
754        Number of pole pairs. Default 8 (24 slots, 16 poles).
755    conductor_area : float, optional
756        Conductor area for the J proxy [m^2]. Default 1, which makes J equal
757        to Im in amps.
758    time_unit : str, optional
759        Override the time unit in the file header ("s", "ms" or "us").
760    inductance : {"incremental", "none"}, optional
761        Fill the L(...) columns with the derived matrix (default) or leave
762        them empty.
763    verbose : bool, optional
764        Print what was written and the checks. Default True.
765
766    Returns
767    -------
768    checks : dict of float
769        The self_check() results.
770
771    Raises
772    ------
773    FileNotFoundError
774        If Psi_d.csv or Psi_q.csv is missing.
775    """
776    psi_d_path, psi_q_path, out_path = Path(psi_d_path), Path(psi_q_path), Path(out_path)
777    missing = [f for f in (psi_d_path, psi_q_path) if not f.exists()]
778    if missing:
779        raise FileNotFoundError(
780            "Could not find the Zenodo flux files:\n  " + "\n  ".join(str(f) for f in missing)
781            + "\nPut Psi_d.csv, Psi_q.csv and Torque.csv in Input_Data/Zenodo_IPM/ "
782              "(or pass the paths, e.g. --psi-d Psi_d.csv --psi-q Psi_q.csv --torque Torque.csv)")
783    torque_path = Path(torque_path) if torque_path is not None else None
784    if torque_path is not None and not torque_path.exists():
785        print(f"Note: no torque file at {torque_path}; skipping the FEA torque summary/check.")
786        torque_path = None
787
788    # Read, convert, check
789    z = load_zenodo(psi_d_path, psi_q_path, torque_path)
790    table, summary, info = build_winding_table(z, pole_pairs, conductor_area, time_unit, inductance)
791    checks = self_check(table, summary, info["n_t"], pole_pairs)
792
793    # Write the winding table, the operating-point summary and the provenance record
794    out_path.parent.mkdir(parents=True, exist_ok=True)
795    table.to_csv(out_path, index=False)
796    summary_path = out_path.with_name(out_path.stem + "_operating_points.csv")
797    summary.to_csv(summary_path, index=False)
798    prov_path = out_path.with_name(out_path.stem + "_provenance.json")
799    params = {"pole_pairs": pole_pairs, "conductor_area": conductor_area}
800    prov_path.write_text(json.dumps(provenance(params, info, checks), indent=2))
801
802    if verbose:
803        print(f"Wrote {out_path}  ({len(table)} rows = {info['n_op']} operating points x {info['n_t']} samples)")
804        print(f"Wrote {summary_path}")
805        print(f"Wrote {prov_path}")
806        print(f"Derived speed: {info['rpm']:.1f} rpm (time unit '{info['time_unit']}')")
807        for k, v in checks.items():
808            print(f"  check {k}: {v:.3g}")
809        if info["inductance"] == "incremental":
810            st = info["inductance_stats"]
811            print("Inductance columns: DERIVED incremental matrix (not Maxwell frozen-permeability).")
812            print(f"  Ld {st['Ld_incremental_uH_range'][0]:.0f}..{st['Ld_incremental_uH_range'][1]:.0f} uH, "
813                  f"Lq {st['Lq_incremental_uH_range'][0]:.0f}..{st['Lq_incremental_uH_range'][1]:.0f} uH, "
814                  f"reciprocity |Ldq-Lqd| median {st['reciprocity_|Ldq-Lqd|_median_uH']:.2f} uH")
815        else:
816            print("Inductance columns left empty (--inductance none).")
817        print(f"Analyse with turns_ratio = 1, stack_factor = 1, pole_pairs = {pole_pairs}.")
818    return checks

821def _default_locations():
822    """Find the folder holding the Zenodo CSVs when no paths are given.
823
824    1. The repository layout: Scripts/create_zenodo_input_data.py with the
825       CSVs in Input_Data/Zenodo_IPM/. Output goes there too.
826    2. Otherwise, the CSVs beside this script, with output beside them.
827
828    Returns
829    -------
830    folder : pathlib.Path
831        The folder to read from and write to. If neither has the CSVs, the
832        repository location is returned and the missing files are reported
833        when the converter runs.
834    """

840        return here

844def main(argv=None):
845    """Run the converter from the command line.
846
847    See Usage in the module docstring for the options.
848
849    Parameters
850    ----------
851    argv : list of str, optional
852        Command-line arguments. Default None (use sys.argv).
853

869                   help="m^2, only used for the J proxy (J = Im / area)")

195    ----------

206

227    4th-order central differences in Gamma) are converted to d/dId and d/dIq
228    with the exact Jacobian of Id = -Im sin(g), Iq = Im cos(g):
229
230        d/dId = -sin(g) d/dIm - cos(g)/Im d/dg
231        d/dIq =  cos(g) d/dIm - sin(g)/Im d/dg
232

606    columns and compares them with the source values. Also compares the
607    flux-formula torque with the FEA torque.

610    ----------
611    table : pandas.DataFrame

613    summary : pandas.DataFrame

631                    table["FluxLinkage(Phase_C) [Wb]"].to_numpy(), th)

641    }

644        # script does) and compare with the dq inductances they were built from
645        n = len(table)
646        c0, c1, c2 = np.cos(th), np.cos(th - 2 * np.pi / 3), np.cos(th + 2 * np.pi / 3)
647        s0, s1, s2 = np.sin(th), np.sin(th - 2 * np.pi / 3), np.sin(th + 2 * np.pi / 3)

650                                np.full((n, 3), 0.5)], 1)

652        col = lambda x, y, unit: table[f"L(Phase_{x},Phase_{y}) [{unit}]"].to_numpy()
653        L = np.empty((n, 3, 3))
654        for i, x in enumerate("ABC"):
655            for j, y in enumerate("ABC"):
656                L[:, i, j] = col(x, y, "uH") * u if x == y else col(x, y, "nH") * nn

658        res["max_err_Ld_from_matrix_uH"] = float(np.max(np.abs(blk(D[:, 0, 0]) * 1e6 - summary["Ld_inc_uH"])))
659        res["max_err_Lq_from_matrix_uH"] = float(np.max(np.abs(blk(D[:, 1, 1]) * 1e6 - summary["Lq_inc_uH"])))

662                                     - summary["Psi_q_Wb"] * summary["Id_A"])
663        err = t_flux - summary["Torque_FEA_Nm"]
664        res["torque_flux_vs_FEA_rms_Nm"] = float(np.sqrt(np.mean(err ** 2)))
665        res["torque_FEA_max_Nm"] = float(summary["Torque_FEA_Nm"].max())
666    return res
