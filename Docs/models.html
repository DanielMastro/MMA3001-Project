models.py - flux models: predict (psi_d, psi_q) at any (Id, Iq).

Where this fits in the project

preprocess.py gives flux only at the FEA operating points (71 unique points for Cobalt). The inverter needs flux, inductance and torque at ANY current, so a model has to be fitted through those points. Four are compared (report section 4, alternative solutions):

constant_inductance()      baseline: psi_d = psi_pm + Ld*Id,  psi_q = Lq*Iq
lookup_table()             baseline: straight lines between the FEA points,
                           what the Simulink lookup tables do now
polynomial_regression(d)   candidate: least-squares fit of a polynomial of
                           degree d in Id and Iq (linear regression)
neural_network(size)       candidate: small neural network, two hidden layers
                           of `size` neurons each

Every model has the same methods, so derive.py and evaluate.py can use any of them (they are documented under _FluxModel below):

model.fit(Id, Iq, psi_d, psi_q)    learn from FEA points (A, Wb)
model.predict_flux(Id, Iq)         -> (psi_d, psi_q) in Wb
model.flux_gradient(Id, Iq)        -> dict of dpsi/di in H (the incremental
                                      inductances)
model.is_extrapolation(Id, Iq)     -> True where a query lies outside the
                                      FEA current range
model.n_parameters                 numbers stored after fitting (memory)
model.flops_per_eval()             rough arithmetic cost of one prediction
Scaling inside every model

Inside every model, currents are divided by the largest training current and flux by the largest training flux, so the model works on numbers of order 1 (per unit). This keeps least squares well conditioned and lets the same settings (polynomial degree, network size) work on a 113 A motor and a 620 A motor. Inputs and outputs of the public methods are always in SI units.

 50def current_angle(Id, Iq):
 51    """Compute the current angle beta in degrees.
 52
 53    Uses beta = atan2(-Id, Iq), the original script's definition: 0 is pure
 54    +q (motoring) and 90 is pure -d (field weakening).
 55
 56    Parameters
 57    ----------
 58    Id : float or array_like
 59        d-axis current [A].
 60    Iq : float or array_like
 61        q-axis current [A].
 62
 63    Returns
 64    -------
 65    beta : numpy.ndarray or float
 66        Current angle [deg], between -180 and 180.
 67    """
 68    return np.degrees(np.arctan2(-np.asarray(Id, dtype=float), np.asarray(Iq, dtype=float)))

 72# SHARED BEHAVIOUR (per-unit scaling, SI in/out, extrapolation flag)

 74class _FluxModel:
 75    """Shared behaviour of every flux model: per-unit scaling, SI in and out.
 76
 77    Not used directly. constant_inductance(), lookup_table(),
 78    polynomial_regression() and neural_network() return subclasses of it, so
 79    every model has the methods documented here. A subclass supplies three
 80    hooks, all in per-unit values (x = Id/I_base, y = Iq/I_base,
 81    pd = psi_d/psi_base, pq = psi_q/psi_base):
 82
 83        _fit(x, y, pd, pq)   learn from the training points
 84        _predict(x, y)       return (pd, pq)
 85        _gradient(x, y)      return an (n, 2, 2) array of slopes [output, input];
 86                             optional, the default uses central differences
 87
 88    Attributes
 89    ----------
 90    name : str
 91        Readable model name.
 92    I_base : float
 93        Largest training current magnitude [A], set by fit().
 94    psi_base : float
 95        Largest training flux linkage magnitude [Wb], set by fit().
 96    beta_range : tuple of float
 97        Smallest and largest training current angle [deg], set by fit().
 98
 99    @public
100    """
101
102    name = "flux model"
103
104    def fit(self, Id, Iq, psi_d, psi_q):
105        """Fit the model to FEA points.
106
107        Parameters
108        ----------
109        Id : array_like
110            d-axis currents [A].
111        Iq : array_like
112            q-axis currents [A].
113        psi_d : array_like
114            d-axis flux linkages [Wb].
115        psi_q : array_like
116            q-axis flux linkages [Wb].
117
118        Returns
119        -------
120        self : flux model
121            The fitted model, so calls can be chained.
122
123        Raises
124        ------
125        ValueError
126            If the four arrays differ in length or contain NaN, or (polynomial
127            regression) there are fewer points than polynomial terms.
128        """
129        Id, Iq, psi_d, psi_q = (np.asarray(v, dtype=float).ravel() for v in (Id, Iq, psi_d, psi_q))
130        if not (len(Id) == len(Iq) == len(psi_d) == len(psi_q)):
131            raise ValueError("Id, Iq, psi_d and psi_q must have the same length")
132        if np.isnan(np.r_[Id, Iq, psi_d, psi_q]).any():
133            raise ValueError("training data contains NaN")
134
135        # Per-unit bases: largest training current and largest training flux
136        self.I_base = float(np.max(np.hypot(Id, Iq)))
137        self.psi_base = float(np.max(np.abs(np.r_[psi_d, psi_q])))
138
139        # Training range, for the extrapolation flag: current angle span of the
140        # non-zero points (the angle is undefined at zero current)
141        on = np.hypot(Id, Iq) > 1e-6 * self.I_base
142        beta = current_angle(Id[on], Iq[on])
143        self.beta_range = (float(beta.min()), float(beta.max()))
144
145        self._fit(Id / self.I_base, Iq / self.I_base, psi_d / self.psi_base, psi_q / self.psi_base)
146        return self
147
148    def predict_flux(self, Id, Iq):
149        """Predict the flux linkages at any operating points.
150
151        Parameters
152        ----------
153        Id : float or array_like
154            d-axis currents [A].
155        Iq : float or array_like
156            q-axis currents [A], broadcastable with Id.
157
158        Returns
159        -------
160        psi_d : numpy.ndarray
161            d-axis flux linkage [Wb], the broadcast shape of Id and Iq.
162        psi_q : numpy.ndarray
163            q-axis flux linkage [Wb], the same shape.
164        """
165        Id, Iq = np.broadcast_arrays(np.asarray(Id, dtype=float), np.asarray(Iq, dtype=float))
166        pd_pu, pq_pu = self._predict(Id.ravel() / self.I_base, Iq.ravel() / self.I_base)
167        return (np.reshape(pd_pu * self.psi_base, Id.shape),
168                np.reshape(pq_pu * self.psi_base, Id.shape))
169
170    def flux_gradient(self, Id, Iq):
171        """Compute the slopes of the predicted flux, the incremental inductances.
172
173        Parameters
174        ----------
175        Id : float or array_like
176            d-axis currents [A].
177        Iq : float or array_like
178            q-axis currents [A], broadcastable with Id.
179
180        Returns
181        -------
182        gradient : dict of numpy.ndarray
183            Slopes [H], each the broadcast shape of Id and Iq: "dpsid_did" (Ld),
184            "dpsiq_diq" (Lq), and the cross-coupling terms "dpsid_diq" and
185            "dpsiq_did".
186        """
187        Id, Iq = np.broadcast_arrays(np.asarray(Id, dtype=float), np.asarray(Iq, dtype=float))
188        g = self._gradient(Id.ravel() / self.I_base, Iq.ravel() / self.I_base)
189        k = self.psi_base / self.I_base          # per-unit slope -> henries
190        shape = Id.shape
191        return {"dpsid_did": np.reshape(g[:, 0, 0] * k, shape),
192                "dpsid_diq": np.reshape(g[:, 0, 1] * k, shape),
193                "dpsiq_did": np.reshape(g[:, 1, 0] * k, shape),
194                "dpsiq_diq": np.reshape(g[:, 1, 1] * k, shape)}
195
196    def _gradient(self, x, y, h=1e-4):
197        """Default gradient hook: central differences on the model itself.
198
199        Used by lookup_table, whose slope is constant inside each triangle.
200
201        Parameters
202        ----------
203        x : numpy.ndarray
204            Per-unit d-axis currents.
205        y : numpy.ndarray
206            Per-unit q-axis currents.
207        h : float, optional
208            Per-unit step. Default 1e-4.
209
210        Returns
211        -------
212        g : numpy.ndarray
213            Shape (n, 2, 2): g[:, output, input] is the slope of per-unit flux
214            (psi_d, psi_q) with per-unit current (Id, Iq).
215        """
216        g = np.empty((len(x), 2, 2))
217        pd_p, pq_p = self._predict(x + h, y); pd_m, pq_m = self._predict(x - h, y)
218        g[:, 0, 0] = (pd_p - pd_m) / (2 * h); g[:, 1, 0] = (pq_p - pq_m) / (2 * h)
219        pd_p, pq_p = self._predict(x, y + h); pd_m, pq_m = self._predict(x, y - h)
220        g[:, 0, 1] = (pd_p - pd_m) / (2 * h); g[:, 1, 1] = (pq_p - pq_m) / (2 * h)
221        return g
222
223    def is_extrapolation(self, Id, Iq, angle_tol_deg=0.5, current_tol=1e-3):
224        """Flag operating points outside the FEA range.
225
226        A point is outside if its current magnitude is larger than any training
227        point's, or its current angle lies outside the training angles.
228        Predictions there are extrapolations.
229
230        Parameters
231        ----------
232        Id : float or array_like
233            d-axis currents [A].
234        Iq : float or array_like
235            q-axis currents [A], broadcastable with Id.
236        angle_tol_deg : float, optional
237            Angle tolerance [deg]. Default 0.5. The FEA's own angles sit about
238            0.04 deg off the axes because of the rotor-alignment step, so a small
239            tolerance stops points on the edge of the sweep being flagged.
240        current_tol : float, optional
241            Current tolerance as a fraction of I_base. Default 1e-3 (0.1 %).
242
243        Returns
244        -------
245        flag : numpy.ndarray of bool
246            True where the point is an extrapolation.
247        """
248        Id, Iq = np.broadcast_arrays(np.asarray(Id, dtype=float), np.asarray(Iq, dtype=float))
249        I = np.hypot(Id, Iq)
250        beta = current_angle(Id, Iq)
251        lo, hi = self.beta_range
252        inside = (I <= self.I_base * (1 + current_tol)) & (
253            (I <= 1e-6 * self.I_base)
254            | ((beta >= lo - angle_tol_deg) & (beta <= hi + angle_tol_deg)))
255        return ~inside
256
257    def __repr__(self):
258        return f"{self.name}"

264class _ConstantInductance(_FluxModel):
265    """Constant-inductance baseline: psi_d = psi_pm + Ld*Id, psi_q = Lq*Iq.
266
267    psi_pm, Ld and Lq are found by least squares. This is what a single
268    Ld/Lq pair assumes: no saturation and no cross-coupling.
269    """
270
271    name = "constant inductance"
272
273    def _fit(self, x, y, pd, pq):
274        """Fit psi_d = a + b*x and psi_q = c*y by least squares (per unit)."""
275        A = np.column_stack([np.ones_like(x), x])                 # [1, Id] for psi_d
276        (self.a, self.b), *_ = np.linalg.lstsq(A, pd, rcond=None)  # psi_d = a + b*Id
277        self.c = np.linalg.lstsq(y[:, None], pq, rcond=None)[0][0] # psi_q = c*Iq
278
279    def _predict(self, x, y):
280        """Per-unit flux from the fitted straight lines."""
281        return self.a + self.b * x, self.c * y
282
283    def _gradient(self, x, y):
284        """Constant slopes: b for Ld and c for Lq, no cross-coupling."""
285        g = np.zeros((len(x), 2, 2))
286        g[:, 0, 0] = self.b                                       # Ld (constant)
287        g[:, 1, 1] = self.c                                       # Lq (constant)
288        return g
289
290    @property
291    def n_parameters(self):
292        """Number of stored parameters: psi_pm, Ld and Lq (3)."""
293        return 3
294
295    def flops_per_eval(self):
296        """Estimate the arithmetic cost of one prediction.
297
298        Returns
299        -------
300        flops : int
301            4 (two multiply-adds).
302        """
303        return 4                                                   # two multiply-adds
304
305    def fitted_values(self):
306        """Return the fitted constants in SI units.
307
308        Returns
309        -------
310        values : dict of float
311            "psi_pm" [Wb], "Ld" [H] and "Lq" [H].
312        """
313        k = self.psi_base / self.I_base
314        return {"psi_pm": self.a * self.psi_base, "Ld": self.b * k, "Lq": self.c * k}

324    -------

326        An unfitted model with the _FluxModel methods plus fitted_values().

329    return _ConstantInductance()

333# BASELINE 2: LOOKUP TABLE (piecewise-linear interpolation)
334# ============================================================================
335class _LookupTable(_FluxModel):
336    """Lookup-table baseline: straight lines between the FEA points.
337
338    The (Id, Iq) plane is split into triangles with the FEA points as
339    corners, and flux is interpolated linearly inside each triangle, so it is
340    exact at every FEA point. Outside the triangles it has no answer, so the
341    nearest FEA point's value is used and the query is flagged as
342    extrapolation.
343    """
344
345    name = "lookup table"
346
347    def _fit(self, x, y, pd, pq):
348        """Build the triangle interpolator and the nearest-point fallback."""
349        pts, vals = np.column_stack([x, y]), np.column_stack([pd, pq])
350        self._linear = LinearNDInterpolator(pts, vals)            # inside the triangles
351        self._nearest = NearestNDInterpolator(pts, vals)          # fallback outside
352        self._n_points = len(x)
353
354    def _predict(self, x, y):
355        """Linear interpolation inside the triangles, nearest point outside them."""
356        out = np.atleast_2d(self._linear(x, y))
357        bad = np.isnan(out).any(axis=1)                           # outside every triangle
358        if bad.any():
359            out[bad] = self._nearest(x[bad], y[bad])
360        return out[:, 0], out[:, 1]
361
362    @property
363    def n_parameters(self):
364        """Number of stored values: Id, Iq, psi_d and psi_q for every point."""
365        return 4 * self._n_points                                  # Id, Iq, psi_d, psi_q per point
366
367    def flops_per_eval(self):
368        """Estimate the arithmetic cost of one prediction.
369
370        Returns
371        -------
372        flops : int
373            About 30: the interpolation weights and blend, plus a triangle search.
374        """
375        return 30                                                  # weights + blend, plus a triangle search

397class _PolynomialRegression(_FluxModel):
398    """Polynomial-regression model fitted by least squares.
399
400    psi = sum of c_ij * Id^i * Iq^j over all i + j <= degree. This is linear
401    regression on polynomial terms. Degree 3 has 10 terms per output
402    (1, Id, Iq, Id^2, Id*Iq, Iq^2, Id^3, ...). The gradient is exact because
403    a polynomial can be differentiated term by term.
404
405    Parameters
406    ----------
407    degree : int
408        Highest total power of Id and Iq.
409
410    Attributes
411    ----------
412    powers : list of tuple of int
413        Exponents (i, j) of every term Id^i * Iq^j.
414    coef : numpy.ndarray
415        Fitted coefficients, shape (number of terms, 2), set by fit().
416    condition_number : float
417        Condition number of the per-unit design matrix, set by fit(); a
418        numerical-stability check.
419    """
420
421    def __init__(self, degree):
422        self.degree = int(degree)
423        self.name = f"polynomial regression (degree {self.degree})"
424        # (i, j) exponent pairs for every term Id^i * Iq^j with i + j <= degree
425        self.powers = [(i, t - i) for t in range(self.degree + 1) for i in range(t, -1, -1)]
426
427    def _design(self, x, y):
428        """Design matrix: one column per polynomial term."""
429        return np.column_stack([x**i * y**j for i, j in self.powers])
430
431    def _fit(self, x, y, pd, pq):
432        """Least-squares fit of the coefficients; ValueError if there are too few points."""
433        A = self._design(x, y)
434        if A.shape[0] < A.shape[1]:
435            raise ValueError(f"degree {self.degree} needs at least {A.shape[1]} points")
436        self.condition_number = float(np.linalg.cond(A))           # numerical stability check
437        self.coef, *_ = np.linalg.lstsq(A, np.column_stack([pd, pq]), rcond=None)
438
439    def _predict(self, x, y):
440        """Per-unit flux from the fitted polynomial."""
441        out = self._design(x, y) @ self.coef
442        return out[:, 0], out[:, 1]
443
444    def _gradient(self, x, y):
445        """Exact gradient, differentiating each term."""
446        zero = np.zeros_like(x)
447        # d/dx of x^i y^j = i x^(i-1) y^j  (and similarly for y); zero when i = 0
448        dA_dx = np.column_stack([i * x**(i - 1) * y**j if i > 0 else zero for i, j in self.powers])
449        dA_dy = np.column_stack([j * x**i * y**(j - 1) if j > 0 else zero for i, j in self.powers])
450        g = np.empty((len(x), 2, 2))
451        g[:, :, 0] = dA_dx @ self.coef                             # d(psi_d, psi_q)/dId
452        g[:, :, 1] = dA_dy @ self.coef                             # d(psi_d, psi_q)/dIq
453        return g
454
455    @property
456    def n_parameters(self):
457        """Number of fitted coefficients: 2 outputs x number of terms."""
458        return self.coef.size                                      # 2 outputs x n_terms
459
460    def flops_per_eval(self):
461        """Estimate the arithmetic cost of one prediction.
462
463        Returns
464        -------
465        flops : int
466            5 per term: building the term and two multiply-adds.
467        """
468        n_terms = len(self.powers)
469        return 5 * n_terms                                         # build each term + 2 multiply-adds
470

488    --------

506class _NeuralNetwork(_FluxModel):
507    """Neural-network model: scikit-learn's MLPRegressor (multilayer perceptron).
508
509        (Id, Iq) -> [size neurons, tanh] -> [size neurons, tanh] -> (psi_d, psi_q)
510
511    tanh is used rather than ReLU because it is smooth. A ReLU network is
512    piecewise linear, so its derivative, the inductance, would come out in
513    steps. Training uses L-BFGS, which suits small datasets. The gradient
514    comes from the chain rule through the trained weights.
515
516    Parameters
517    ----------
518    size : int
519        Neurons in each of the two hidden layers.
520    seed : int, optional
521        Random seed for the starting weights. Default 0.
522
523    Attributes
524    ----------
525    converged : bool
526        False if L-BFGS stopped at its 5000-iteration limit; set by fit().
527    """
528
529    def __init__(self, size, seed=0):
530        self.size = int(size)
531        self.seed = seed
532        self.name = f"neural network (size {self.size})"
533
534    def _fit(self, x, y, pd, pq):
535        """Train the network with L-BFGS on standardised per-unit outputs."""
536        from sklearn.exceptions import ConvergenceWarning
537        from sklearn.neural_network import MLPRegressor
538
539        X = np.column_stack([x, y])
540        Y = np.column_stack([pd, pq])
541        # Standardise the two outputs so both are weighted equally in training
542        self._y_mean, self._y_std = Y.mean(axis=0), Y.std(axis=0)
543        self._y_std[self._y_std == 0] = 1.0
544        self._net = MLPRegressor(hidden_layer_sizes=(self.size, self.size), activation="tanh",
545                                 solver="lbfgs", max_iter=5000, random_state=self.seed)
546        with warnings.catch_warnings(record=True) as caught:
547            warnings.simplefilter("always", ConvergenceWarning)
548            self._net.fit(X, (Y - self._y_mean) / self._y_std)
549        self.converged = not any(issubclass(w.category, ConvergenceWarning) for w in caught)
550
551    def _predict(self, x, y):
552        """Per-unit flux from the trained network."""
553        out = self._net.predict(np.column_stack([x, y])) * self._y_std + self._y_mean
554        return out[:, 0], out[:, 1]
555
556    def _gradient(self, x, y):
557        """Exact gradient by the chain rule through the trained weights."""
558        W1, W2, W3 = self._net.coefs_                 # (2, s), (s, s), (s, 2)
559        b1, b2, _ = self._net.intercepts_
560        X = np.column_stack([x, y])
561        h1 = np.tanh(X @ W1 + b1)                      # hidden layer 1 outputs (n, s)
562        h2 = np.tanh(h1 @ W2 + b2)                     # hidden layer 2 outputs (n, s)
563        # Chain rule, layer by layer (d tanh(z)/dz = 1 - tanh(z)^2)
564        dh1 = (1 - h1**2)[:, :, None] * W1.T[None, :, :]           # dh1/dX  (n, s, 2)
565        dh2 = (1 - h2**2)[:, :, None] * np.einsum("km,nki->nmi", W2, dh1)   # dh2/dX
566        dout = np.einsum("mo,nmi->noi", W3, dh2)                   # d(standardised out)/dX
567        return dout * self._y_std[None, :, None]                   # undo the output scaling
568
569    @property
570    def n_parameters(self):
571        """Number of weights and biases."""
572        return int(sum(w.size for w in self._net.coefs_) + sum(b.size for b in self._net.intercepts_))
573
574    def flops_per_eval(self):
575        """Estimate the arithmetic cost of one prediction.
576
577        Returns
578        -------
579        flops : int
580            Two per multiply-add in the three weight layers, plus about 20 per
581            tanh evaluation.
582        """
583        s = self.size
584        mult_adds = 2 * s + s * s + 2 * s                          # three weight layers
585        return 2 * mult_adds + 2 * s * 20                          # + about 20 flops per tanh

198        """Default gradient hook: central differences on the model itself.
199
200        Used by lookup_table, whose slope is constant inside each triangle.
201
202        Parameters
203        ----------
204        x : numpy.ndarray
205            Per-unit d-axis currents.
206        y : numpy.ndarray
207            Per-unit q-axis currents.
208        h : float, optional
209            Per-unit step. Default 1e-4.
210
211        Returns
212        -------
213        g : numpy.ndarray
214            Shape (n, 2, 2): g[:, output, input] is the slope of per-unit flux
215            (psi_d, psi_q) with per-unit current (Id, Iq).
216        """
217        g = np.empty((len(x), 2, 2))
218        pd_p, pq_p = self._predict(x + h, y); pd_m, pq_m = self._predict(x - h, y)
219        g[:, 0, 0] = (pd_p - pd_m) / (2 * h); g[:, 1, 0] = (pq_p - pq_m) / (2 * h)
220        pd_p, pq_p = self._predict(x, y + h); pd_m, pq_m = self._predict(x, y - h)
221        g[:, 0, 1] = (pd_p - pd_m) / (2 * h); g[:, 1, 1] = (pq_p - pq_m) / (2 * h)
222        return g
