preprocess

preprocess.py - winding table -> flux map. Refactored from History/preprocess_v3.py, the original inductance script.

Where this fits in the project

This is the first stage of the pipeline. It reads one FEA winding table in the Ansys Maxwell export format and returns one row per operating point holding Id, Iq, psi_d, psi_q, the inductances and torque. The two inputs are:

Input_Data/Cobalt/cobalt_input_data.csv          the team's Maxwell 2D FEA
Input_Data/Zenodo_IPM/zenodo_input_data.csv      open IPM data, converted to
                                                 this format by
                                                 create_zenodo_input_data.py

models.py then fits flux models to this table, and evaluate.py checks them.

Pipeline steps

The same methods and results as History/preprocess_v3.py:

  1. load_winding_table() read the CSV and check it is usable
  2. rotor_angle() rotor electrical angle at every step, read from the direction of the no-load (J = 0) flux
  3. dq_per_row() Park transform of currents, flux and the 3x3 inductance matrix at that rotor angle
  4. average_cycles() average each operating point over a whole number of electrical cycles (numerical integration)
  5. scale() 2-turn 2D model -> real machine (turns ratio, stack factor)
  6. pm_flux() psi_pm and the cross-saturated psi_pm_eff(Iq)
  7. grid_inductances() incremental inductances by finite differences on the FEA grid, and apparent inductances, as in the original

build_flux_map() runs all seven and adds torque.

Changes from the original script
  • The code is split into functions, and the settings (file, turns ratio, stack factor, pole pairs) are arguments rather than constants at the top. That lets the same code run on both motors, be tested with pytest and be documented with pdoc. Cobalt: turns_ratio=33/2, stack_factor=0.9, pole_pairs=5. Zenodo: 1, 1, 8.
  • The Park transform of the inductance matrix is done for all rows at once (vectorised). The original row-by-row iterrows loop is kept, selectable with inductance_method="loop", so evaluate.py can time the two against each other. Both give the same numbers.
  • Steps per electrical cycle use the MEAN rotor-angle step instead of the median. Cobalt still gets 16 steps. Zenodo's 60 small steps carry slot ripple, which can push the median far enough to round to 59.
  • The incremental-inductance table is assembled without DataFrame.stack(), and merged with how="left". The results are the same, but the J = 0 rows are kept on every pandas version.
  • Torque now uses the flux formula (derive.torque_from_flux). The original matrix-inductance formula is kept as the column Torque_matrix_Nm for comparison only (evaluate.torque_formula_comparison).

 88# PARK / CLARKE (amplitude-invariant, 2/3 convention) - unchanged from preprocess_v3

 90def park_vec(a, b, c, theta):
 91    """Park-transform a three-phase quantity (abc -> dq0).
 92
 93    Amplitude-invariant (2/3) convention: a balanced set of peak amplitude X
 94    gives |dq| = X. Used for currents, flux linkages and voltages.
 95
 96    Parameters
 97    ----------
 98    a : float or array_like
 99        Phase A value.
100    b : float or array_like
101        Phase B value.
102    c : float or array_like
103        Phase C value.
104    theta : float or array_like
105        Rotor electrical angle [rad].
106
107    Returns
108    -------
109    d : numpy.ndarray or float
110        d-axis component.
111    q : numpy.ndarray or float
112        q-axis component.
113    z : numpy.ndarray or float
114        Zero-sequence component, (a + b + c) / 3.
115    """
116    d = (2/3) * (a*np.cos(theta) + b*np.cos(theta - 2*np.pi/3) + c*np.cos(theta + 2*np.pi/3))
117    q = -(2/3) * (a*np.sin(theta) + b*np.sin(theta - 2*np.pi/3) + c*np.sin(theta + 2*np.pi/3))
118    z = (1/3) * (a + b + c)
119    return d, q, z

122def park_matrix(theta):
123    """Build the 3x3 Park matrix T(theta), so that [d, q, 0] = T @ [a, b, c].
124
125    Parameters
126    ----------
127    theta : float
128        Rotor electrical angle [rad].
129
130    Returns
131    -------
132    T : numpy.ndarray
133        Amplitude-invariant Park matrix, shape (3, 3).
134    """
135    return (2/3) * np.array([
136        [np.cos(theta), np.cos(theta - 2*np.pi/3), np.cos(theta + 2*np.pi/3)],
137        [-np.sin(theta), -np.sin(theta - 2*np.pi/3), -np.sin(theta + 2*np.pi/3)],
138        [0.5, 0.5, 0.5],
139    ])

142def dq_inductances_matrix(row, theta):
143    """Park-transform one row's 3x3 phase inductance matrix.
144
145    Computes L_dq0 = T @ L_abc @ inv(T) for ONE row. This is the original
146    script's per-row version, used by dq_per_row(inductance_method="loop")
147    and kept so the vectorised version can be timed against it.
148
149    Parameters
150    ----------
151    row : pandas.Series
152        One row with the working columns Laa, Lab, ... Lcc [H].
153    theta : float
154        Rotor electrical angle [rad].
155
156    Returns
157    -------
158    Ld : float
159        d-axis inductance [H].
160    Lq : float
161        q-axis inductance [H].
162    """
163    T = park_matrix(theta)
164    L = np.array([
165        [row["Laa"], row["Lab"], row["Lac"]],
166        [row["Lba"], row["Lbb"], row["Lbc"]],
167        [row["Lca"], row["Lcb"], row["Lcc"]],
168    ])
169    D = T @ L @ np.linalg.inv(T)
170    return D[0, 0], D[1, 1]

173def park_matrix_stack(theta):
174    """Build the Park matrices for many angles at once.
175
176    Parameters
177    ----------
178    theta : array_like
179        Rotor electrical angles [rad], n values.
180
181    Returns
182    -------
183    T : numpy.ndarray
184        Shape (n, 3, 3); T[k] equals park_matrix(theta[k]).
185    """
186    theta = np.asarray(theta, dtype=float)
187    T = np.empty((theta.size, 3, 3))
188    T[:, 0, 0] = np.cos(theta)
189    T[:, 0, 1] = np.cos(theta - 2*np.pi/3)
190    T[:, 0, 2] = np.cos(theta + 2*np.pi/3)
191    T[:, 1, 0] = -np.sin(theta)
192    T[:, 1, 1] = -np.sin(theta - 2*np.pi/3)
193    T[:, 1, 2] = -np.sin(theta + 2*np.pi/3)
194    T[:, 2, :] = 0.5
195    return (2/3) * T

201def load_winding_table(path):
202    """Read a winding-table CSV and check it can be processed.
203
204    NaN in the inductance-matrix columns only prints a warning: those
205    columns are optional, and their dq values will be NaN.
206
207    Parameters
208    ----------
209    path : str or pathlib.Path
210        Winding-table CSV in the Ansys Maxwell export format, with the
211        columns in REQUIRED_COLUMNS.
212
213    Returns
214    -------
215    raw : pandas.DataFrame
216        The file as read, units unchanged.
217
218    Raises
219    ------
220    FileNotFoundError
221        If the file does not exist.
222    ValueError
223        If a required column is missing; a current, flux or setting column
224        contains NaN; the row count is not a whole number of operating-point
225        blocks (NStepsPerElectricalCycle + 1 rows each); there are no
226        no-load (J = 0) rows, which the rotor angle is read from; or the
227        phase currents do not sum to zero (an unbalanced or mislabelled set).
228    """
229    path = Path(path)
230    if not path.exists():
231        raise FileNotFoundError(f"Winding table not found: {path}")
232    raw = pd.read_csv(path)
233
234    missing = [c for c in REQUIRED_COLUMNS if c not in raw.columns]
235    if missing:
236        raise ValueError(f"{path.name} is missing columns: {missing}")
237
238    core = [c for c in REQUIRED_COLUMNS if c not in INDUCTANCE_COLUMNS]
239    if raw[core].isna().to_numpy().any():
240        raise ValueError(f"{path.name} contains NaN values in: "
241                         f"{[c for c in core if raw[c].isna().any()]}")
242    if raw[INDUCTANCE_COLUMNS].isna().to_numpy().any():
243        print(f"Warning: {path.name} has NaN inductance-matrix values; "
244              "matrix Ld/Lq will be NaN (flux-derived inductances are unaffected).")
245
246    block = int(raw[COL_NSTEPS].iloc[0]) + 1
247    if len(raw) % block != 0:
248        raise ValueError(f"{path.name}: {len(raw)} rows is not a whole number of "
249                         f"{block}-row operating-point blocks.")
250    if not (raw[COL_J] == 0).any():
251        raise ValueError(f"{path.name} has no no-load (J = 0) rows; "
252                         "the rotor angle cannot be found.")
253
254    i_sum = (raw["InputCurrent(Phase_A) [mA]"] + raw["InputCurrent(Phase_B) [mA]"]
255             + raw["InputCurrent(Phase_C) [mA]"]).abs().max()
256    i_max = raw["InputCurrent(Phase_A) [mA]"].abs().max()
257    if i_max > 0 and i_sum > 1e-3 * i_max:
258        raise ValueError(f"{path.name}: phase currents do not sum to zero "
259                         f"(max |ia+ib+ic| = {i_sum:.3g} mA).")
260    return raw

263def working_columns(data):
264    """Add the working columns, converting unit prefixes only.
265
266    Inductances uH/nH -> H (Laa ... Lcc) and currents mA -> A (ia, ib, ic);
267    flux is already in Wb (fa, fb, fc). The same conversions as the original
268    script.
269
270    Parameters
271    ----------
272    data : pandas.DataFrame
273        Raw winding-table rows.
274
275    Returns
276    -------
277    data : pandas.DataFrame
278        The same DataFrame with the working columns added.
279    """
280    data["Laa"] = data["L(Phase_A,Phase_A) [uH]"] * 1e-6
281    data["Lbb"] = data["L(Phase_B,Phase_B) [uH]"] * 1e-6
282    data["Lcc"] = data["L(Phase_C,Phase_C) [uH]"] * 1e-6
283    data["Lab"] = data["L(Phase_A,Phase_B) [nH]"] * 1e-9
284    data["Lac"] = data["L(Phase_A,Phase_C) [nH]"] * 1e-9
285    data["Lba"] = data["L(Phase_B,Phase_A) [nH]"] * 1e-9
286    data["Lbc"] = data["L(Phase_B,Phase_C) [nH]"] * 1e-9
287    data["Lca"] = data["L(Phase_C,Phase_A) [nH]"] * 1e-9
288    data["Lcb"] = data["L(Phase_C,Phase_B) [nH]"] * 1e-9
289
290    data["ia"] = data["InputCurrent(Phase_A) [mA]"] * 1e-3
291    data["ib"] = data["InputCurrent(Phase_B) [mA]"] * 1e-3
292    data["ic"] = data["InputCurrent(Phase_C) [mA]"] * 1e-3
293
294    data["fa"] = data["FluxLinkage(Phase_A) [Wb]"]
295    data["fb"] = data["FluxLinkage(Phase_B) [Wb]"]
296    data["fc"] = data["FluxLinkage(Phase_C) [Wb]"]
297    return data

301# 2. ROTOR ELECTRICAL ANGLE + INTEGER-CYCLE ROW SELECTION

303def rotor_angle(raw, rotor_mode="from_flux", rotor_ref_deg=0.0, auto_align=True,
304                init_period_to_remove=0.5, num_periods=1.5, elec_deg_per_cycle=360.0,
305                verbose=True):
306    """Add the rotor electrical angle "theta" [rad] to every row.
307
308    The original script's logic. With the default rotor_mode "from_flux" the
309    angle is read from the no-load flux: at no load the flux points along
310    the d-axis, so the rotor angle at each step IS the angle of the no-load
311    flux. It is read from the J = 0 blocks and averaged across them (a
312    circular mean). Only the first n_keep rows of each block are kept, a
313    whole number of electrical cycles, so the averaging in average_cycles()
314    is not biased. Cobalt stores 1.5 cycles in 25 rows and keeps 16; Zenodo
315    stores 1 cycle in 61 rows and keeps 60.
316
317    Parameters
318    ----------
319    raw : pandas.DataFrame
320        Output of load_winding_table().
321    rotor_mode : {"from_flux", "fixed", "sweep"}, optional
322        How the angle is found. "from_flux" (default) as above. "fixed" uses
323        one constant angle, rotor_ref_deg, optionally auto-aligned so the
324        no-load psi_q is zero. "sweep" is the legacy method: the angle is
325        rebuilt from the step index, which needs init_period_to_remove,
326        num_periods and elec_deg_per_cycle to be right.
327    rotor_ref_deg : float, optional
328        Reference angle [deg] for "fixed" and "sweep". Default 0.
329    auto_align : bool, optional
330        "fixed" only: shift the angle so the mean no-load psi_q is zero.
331        Default True.
332    init_period_to_remove : float, optional
333        "sweep" only: electrical periods dropped from the start of each
334        block. Default 0.5.
335    num_periods : float, optional
336        "sweep" only: electrical periods stored in each block. Default 1.5.
337    elec_deg_per_cycle : float, optional
338        "sweep" only: electrical degrees covered by one block's steps, so the
339        step is elec_deg_per_cycle / NStepsPerElectricalCycle. Default 360.
340    verbose : bool, optional
341        Print the detected sweep. Default True.
342
343    Returns
344    -------
345    data : pandas.DataFrame
346        The kept rows, with the working columns and "theta" added.
347
348    Raises
349    ------
350    ValueError
351        If rotor_mode is unknown, or "from_flux" does not find whole no-load
352        blocks.
353    """
354    n_steps_col = int(raw[COL_NSTEPS].iloc[0])
355    block = n_steps_col + 1          # rows per operating point (25 Cobalt, 61 Zenodo)
356
357    # ---- which rows to keep (preprocess_v3 "LOAD" section) ----
358    if rotor_mode == "sweep":
359        remove_rows = int(np.floor(n_steps_col * init_period_to_remove / num_periods))
360        idx = (np.arange(len(raw))
361               .reshape(-1, block)[:, remove_rows:]
362               .flatten())
363        data = raw.iloc[idx].copy()
364    else:
365        data = raw.copy()
366    data = working_columns(data)
367
368    if rotor_mode == "from_flux":
369        nl = raw[raw[COL_J] == 0]
370        if len(nl) == 0 or len(nl) % block != 0:
371            raise ValueError(
372                f"from_flux needs whole no-load blocks. Found {len(nl)} J=0 rows, "
373                f"block size = {block}.")
374        a0 = nl["FluxLinkage(Phase_A) [Wb]"].to_numpy()
375        b0 = nl["FluxLinkage(Phase_B) [Wb]"].to_numpy()
376        c0 = nl["FluxLinkage(Phase_C) [Wb]"].to_numpy()
377        d0, q0, _ = park_vec(a0, b0, c0, 0.0)               # theta = 0 -> stationary alpha, beta
378        ang = np.unwrap(np.arctan2(q0, d0).reshape(-1, block), axis=1)
379        theta_step = np.unwrap(np.angle(np.exp(1j * ang).mean(axis=0)))   # circular mean per step
380
381        # Mean step (preprocess_v3 used the median; see the module docstring)
382        step_deg = np.rad2deg(np.mean(np.diff(theta_step)))
383        span_deg = np.rad2deg(theta_step[-1] - theta_step[0])
384        n_per_cycle = int(round(360.0 / step_deg))
385        n_keep = min(n_per_cycle * max(1, int(round(span_deg, 6) // 360)), block)
386        if verbose:
387            print(f"Rotor sweep per block: {span_deg:.1f} elec deg in steps of "
388                  f"{step_deg:.2f} deg ({span_deg/360:.2f} cycles)")
389            print(f"Averaging over first {n_keep} rows = "
390                  f"{n_keep*step_deg:.0f} deg (integer cycles)")
391
392        if len(data) % block != 0:
393            raise ValueError("Row count is not a whole number of blocks.")
394        data["theta"] = np.tile(theta_step, len(data) // block)
395        data["step_in_block"] = np.tile(np.arange(block), len(data) // block)
396        data = data[data["step_in_block"] < n_keep].copy()
397
398    elif rotor_mode == "sweep":
399        remove_rows = int(np.floor(n_steps_col * init_period_to_remove / num_periods))
400        kept = n_steps_col + 1 - remove_rows
401        step_in_cycle = np.tile(np.arange(remove_rows, n_steps_col + 1),
402                                len(data) // kept + 1)[:len(data)]
403        data["theta"] = (np.deg2rad(rotor_ref_deg)
404                         + step_in_cycle * np.deg2rad(elec_deg_per_cycle / n_steps_col))
405
406    elif rotor_mode == "fixed":
407        data["theta"] = np.full(len(data), np.deg2rad(rotor_ref_deg))
408        if auto_align:
409            nl = data[data[COL_J] == 0]
410            d0, q0, _ = park_vec(nl["fa"].to_numpy(), nl["fb"].to_numpy(),
411                                 nl["fc"].to_numpy(), nl["theta"].to_numpy())
412            delta = np.arctan2(np.mean(q0), np.mean(d0))
413            data["theta"] = data["theta"] + delta
414            if verbose:
415                print(f"Auto-align: d-axis shifted by {np.rad2deg(delta):+.3f} deg")
416    else:
417        raise ValueError("rotor_mode must be 'from_flux', 'fixed' or 'sweep'")
418    return data

424def dq_per_row(data, inductance_method="vectorised"):
425    """Park-transform every row at its rotor angle.
426
427    Adds id_raw, iq_raw, psi_d_raw and psi_q_raw (model turns, before
428    scaling), and Ldm_raw and Lqm_raw, the dq transform of the Maxwell
429    inductance matrix.
430
431    Parameters
432    ----------
433    data : pandas.DataFrame
434        Output of rotor_angle().
435    inductance_method : {"vectorised", "loop"}, optional
436        "vectorised" (default) computes T @ L @ inv(T) for every row at once.
437        "loop" is the original script's row-by-row iterrows loop, slow and
438        kept for timing. Both compute exactly the same matrix product.
439
440    Returns
441    -------
442    data : pandas.DataFrame
443        The same DataFrame with the dq columns added.
444
445    Raises
446    ------
447    ValueError
448        If inductance_method is not "vectorised" or "loop".
449    """
450    th = data["theta"].to_numpy()
451    d_i, q_i, _ = park_vec(data["ia"].to_numpy(), data["ib"].to_numpy(),
452                           data["ic"].to_numpy(), th)
453    d_f, q_f, _ = park_vec(data["fa"].to_numpy(), data["fb"].to_numpy(),
454                           data["fc"].to_numpy(), th)
455    data["id_raw"], data["iq_raw"] = d_i, q_i
456    data["psi_d_raw"], data["psi_q_raw"] = d_f, q_f
457
458    if inductance_method == "loop":
459        # preprocess_v3, unchanged: one 3x3 matrix product per row
460        Ldm, Lqm = [], []
461        for _, row in data.iterrows():
462            a, b = dq_inductances_matrix(row, row["theta"])
463            Ldm.append(a); Lqm.append(b)
464    elif inductance_method == "vectorised":
465        # Stack every row's 3x3 abc matrix into one (n, 3, 3) array
466        L = np.empty((len(data), 3, 3))
467        L[:, 0, 0], L[:, 0, 1], L[:, 0, 2] = data["Laa"], data["Lab"], data["Lac"]
468        L[:, 1, 0], L[:, 1, 1], L[:, 1, 2] = data["Lba"], data["Lbb"], data["Lbc"]
469        L[:, 2, 0], L[:, 2, 1], L[:, 2, 2] = data["Lca"], data["Lcb"], data["Lcc"]
470        T = park_matrix_stack(th)
471        D = T @ L @ np.linalg.inv(T)            # same product as preprocess_v3, all rows at once
472        Ldm, Lqm = D[:, 0, 0], D[:, 1, 1]
473    else:
474        raise ValueError("inductance_method must be 'vectorised' or 'loop'")
475    data["Ldm_raw"], data["Lqm_raw"] = Ldm, Lqm
476    return data

480# 4. COLLAPSE EACH OPERATING POINT (average over whole electrical cycles)
481# ============================================================================
482def average_cycles(data):
483    """Average each operating point over whole electrical cycles.
484
485    Gives one row per operating point (J, TimingAdjustment), holding the
486    mean of every kept row. Because rotor_angle() kept a whole number of
487    cycles, this mean is the cycle average: the integral over a period
488    divided by the period (rectangle rule).
489
490    Parameters
491    ----------
492    data : pandas.DataFrame
493        Output of dq_per_row().
494
495    Returns
496    -------
497    m : pandas.DataFrame
498        One row per operating point: J, TimingAdjustment and the means of
499        id_raw, iq_raw, psi_d_raw, psi_q_raw, Ldm_raw and Lqm_raw.
500    """
501    return data.groupby([COL_J, COL_TIMING]).agg(
502        id_raw=("id_raw", "mean"),
503        iq_raw=("iq_raw", "mean"),
504        psi_d_raw=("psi_d_raw", "mean"),
505        psi_q_raw=("psi_q_raw", "mean"),
506        Ldm_raw=("Ldm_raw", "mean"),
507        Lqm_raw=("Lqm_raw", "mean"),
508    ).reset_index()

511# ============================================================================
512# 5. SCALE TO REAL MACHINE
513# ============================================================================
514def scale(m, turns_ratio, stack_factor):
515    """Scale the 2D model's values to the real machine.
516
517    Flux scales with N*s, current with 1/N and inductance with N^2*s, where
518    N is the turns ratio and s the stack factor.
519
520    Parameters
521    ----------
522    m : pandas.DataFrame
523        Output of average_cycles().
524    turns_ratio : float
525        Real turns / model turns (Cobalt 33/2).
526    stack_factor : float
527        2D-to-3D correction for field quantities (Cobalt 0.9).
528
529    Returns
530    -------
531    m : pandas.DataFrame
532        The same DataFrame with Id, Iq [A], Psi_d, Psi_q, Psi_mag [Wb] and
533        Ld_matrix, Lq_matrix [H] added.
534    """
535    N, s = turns_ratio, stack_factor
536    m["Id"] = m["id_raw"] / N
537    m["Iq"] = m["iq_raw"] / N
538    m["Psi_d"] = m["psi_d_raw"] * N * s
539    m["Psi_q"] = m["psi_q_raw"] * N * s
540    m["Ld_matrix"] = m["Ldm_raw"] * N**2 * s
541    m["Lq_matrix"] = m["Lqm_raw"] * N**2 * s
542    m["Psi_mag"] = np.hypot(m["Psi_d"], m["Psi_q"])
543    return m

546# ============================================================================
547# 6. PM FLUX
548# ============================================================================
549def pm_flux(m, verbose=True):
550    """Find the magnet flux psi_pm and the cross-saturated psi_pm_eff(Iq).
551
552    psi_pm is the no-load psi_d. psi_pm_eff(Iq) is psi_d along the Id = 0
553    line: q-axis current saturates iron shared with the magnet flux path, so
554    the flux the magnets effectively link drops with |Iq|. It is built from
555    the near-zero-Id operating points and interpolated to every row's |Iq|
556    (an even function of Iq). The same definition as the original script.
557
558    Parameters
559    ----------
560    m : pandas.DataFrame
561        Output of scale().
562    verbose : bool, optional
563        Print psi_pm and the cross-saturation. Default True.
564
565    Returns
566    -------
567    m : pandas.DataFrame
568        The same DataFrame with Psi_pm_eff [Wb] added.
569    psi_pm : float
570        No-load magnet flux linkage [Wb].
571
572    Raises
573    ------
574    ValueError
575        If there are fewer than three operating points near Id = 0.
576    """
577    psi_pm = m.loc[m[COL_J] == 0, "Psi_d"].mean()
578    psi_q_nl = m.loc[m[COL_J] == 0, "Psi_q"].abs().mean()
579    if verbose:
580        print(f"\npsi_pm = {psi_pm:.6f} Wb   (no-load |psi_q| = {psi_q_nl:.2e} Wb, ~0 if aligned)")
581
582    I_tot = np.hypot(m["Id"], m["Iq"])
583    on_axis = np.abs(m["Id"]) < np.maximum(0.5, 0.02 * I_tot)
584    line = (m.loc[on_axis, ["Iq", "Psi_d"]]
585              .assign(aIq=lambda x: x["Iq"].abs().round(3))
586              .groupby("aIq")["Psi_d"].mean().sort_index())
587    if len(line) < 3:
588        raise ValueError("Not enough Id~0 points to build psi_pm_eff(Iq).")
589    m["Psi_pm_eff"] = np.interp(np.abs(m["Iq"]), line.index.to_numpy(), line.to_numpy())
590    if verbose:
591        print(f"psi_pm_eff(Iq): {line.iloc[0]:.5f} Wb at Iq=0  ->  "
592              f"{line.iloc[-1]:.5f} Wb at |Iq|={line.index[-1]:.0f} A "
593              f"({100*(line.iloc[-1]-line.iloc[0])/line.iloc[0]:+.1f}% cross-saturation)")
594    return m, psi_pm

597# ============================================================================
598# 7. INDUCTANCES ON THE FEA GRID (preprocess_v3's incremental + apparent sections)
599# ============================================================================
600def grid_inductances(m):
601    """Compute incremental and apparent inductances at the FEA points.
602
603    Incremental: finite differences (np.gradient, 3-point central) on the
604    polar J x TimingAdjustment grid, then the chain rule (a 2x2 Jacobian
605    solve) to get d/dId and d/dIq. They are NaN at J = 0, where the polar
606    grid collapses to a point.
607
608    Apparent: Ld_app = (psi_d - psi_pm_eff) / Id and Lq_app = psi_q / Iq.
609    The 0/0 points are filled with their limits, the incremental values.
610
611    Parameters
612    ----------
613    m : pandas.DataFrame
614        Output of pm_flux().
615
616    Returns
617    -------
618    m : pandas.DataFrame
619        A new DataFrame with Ld_inc, Ldq_inc, Lqd_inc, Lq_inc, Ld_app and
620        Lq_app [H] added, plus Saliency = Lq_matrix / Ld_matrix (the original
621        script's exported saliency).
622    """
623    Jv = np.sort(m[COL_J].unique())
624    Tv = np.sort(m[COL_TIMING].unique())
625
626    def pivot(col):
627        return m.pivot(index=COL_J, columns=COL_TIMING, values=col).loc[Jv, Tv].to_numpy()
628
629    Id_g, Iq_g = pivot("Id"), pivot("Iq")
630    Pd_g, Pq_g = pivot("Psi_d"), pivot("Psi_q")
631
632    # Derivatives along the two grid directions (current magnitude J, angle T)
633    dId_dJ, dId_dT = np.gradient(Id_g)
634    dIq_dJ, dIq_dT = np.gradient(Iq_g)
635    dPd_dJ, dPd_dT = np.gradient(Pd_g)
636    dPq_dJ, dPq_dT = np.gradient(Pq_g)
637
638    Ldd = np.full_like(Id_g, np.nan)   # dPsi_d/dId
639    Ldq = np.full_like(Id_g, np.nan)   # dPsi_d/dIq  (cross-saturation)
640    Lqd = np.full_like(Id_g, np.nan)   # dPsi_q/dId
641    Lqq = np.full_like(Id_g, np.nan)   # dPsi_q/dIq
642    for i in range(Id_g.shape[0]):
643        for j in range(Id_g.shape[1]):
644            # Chain rule: [dpsi/dJ, dpsi/dT] = Jac @ [dpsi/dId, dpsi/dIq]
645            Jac = np.array([[dId_dJ[i, j], dIq_dJ[i, j]],
646                            [dId_dT[i, j], dIq_dT[i, j]]])
647            if abs(np.linalg.det(Jac)) < 1e-12:
648                continue                      # singular at J=0 (grid collapses)
649            inv = np.linalg.inv(Jac)
650            gd = inv @ np.array([dPd_dJ[i, j], dPd_dT[i, j]])
651            gq = inv @ np.array([dPq_dJ[i, j], dPq_dT[i, j]])
652            Ldd[i, j], Ldq[i, j] = gd
653            Lqd[i, j], Lqq[i, j] = gq
654
655    # Back to one row per operating point (the same as preprocess_v3's .stack(), but
656    # without dropping the NaN J=0 rows on older pandas versions)
657    JJ, TT = np.meshgrid(Jv, Tv, indexing="ij")
658    inc = pd.DataFrame({COL_J: JJ.ravel(), COL_TIMING: TT.ravel(),
659                        "Ld_inc": Ldd.ravel(), "Ldq_inc": Ldq.ravel(),
660                        "Lqd_inc": Lqd.ravel(), "Lq_inc": Lqq.ravel()})
661    m = m.merge(inc, on=[COL_J, COL_TIMING], how="left")
662
663    # ---- apparent (secant) inductances ----
664    I_tot = np.hypot(m["Id"], m["Iq"])
665    ok_d = (np.abs(m["Id"]) > 0.02 * I_tot) & (np.abs(m["Id"]) > 0.5)
666    ok_q = (np.abs(m["Iq"]) > 0.02 * I_tot) & (np.abs(m["Iq"]) > 0.5)
667    m["Ld_app"] = np.where(ok_d, (m["Psi_d"] - m["Psi_pm_eff"]) / m["Id"], np.nan)
668    m["Lq_app"] = np.where(ok_q, m["Psi_q"] / m["Iq"], np.nan)
669
670    # Fill undefined 0/0 points with their mathematical limits (the incremental
671    # values), so the grid is complete
672    m["Ld_app"] = m["Ld_app"].fillna(m["Ld_inc"])
673    m["Lq_app"] = m["Lq_app"].fillna(m["Lq_inc"])
674    pure_d = m.loc[m["Ld_inc"].notna() & (np.abs(m["Iq"]) < 0.5), "Ld_inc"]
675    pure_q = m.loc[m["Lq_inc"].notna() & (np.abs(m["Id"]) < 0.5), "Lq_inc"]
676    m["Ld_app"] = m["Ld_app"].fillna(pure_d.iloc[0] if len(pure_d) else np.nan)
677    m["Lq_app"] = m["Lq_app"].fillna(pure_q.iloc[0] if len(pure_q) else np.nan)
678
679    # Saliency from the matrix inductances, as preprocess_v3 exported it
680    m["Saliency"] = m["Lq_matrix"] / m["Ld_matrix"]
681    return m

687def attach_fea_torque(m, operating_points_csv):
688    """Add the FEA's own torque, matched on (J, TimingAdjustment).
689
690    The Zenodo FEA computed torque directly. create_zenodo_input_data.py
691    saves it, averaged per operating point, in
692    zenodo_input_data_operating_points.csv. It is the independent check for
693    derive.torque_from_flux(). A warning is printed if some points have no
694    match.
695
696    Parameters
697    ----------
698    m : pandas.DataFrame
699        Flux map.
700    operating_points_csv : str or pathlib.Path
701        The converter's operating-point summary, with column Torque_FEA_Nm.
702
703    Returns
704    -------
705    m : pandas.DataFrame
706        A new DataFrame with Torque_FEA_Nm [Nm] added.
707    """
708    op = pd.read_csv(operating_points_csv)
709    key = lambda df: pd.DataFrame({"_J": df[COL_J].round(6), "_T": df[COL_TIMING].round(6)})
710    left = pd.concat([m, key(m)], axis=1)
711    right = pd.concat([key(op), op[["Torque_FEA_Nm"]]], axis=1).drop_duplicates(["_J", "_T"])
712    out = left.merge(right, on=["_J", "_T"], how="left").drop(columns=["_J", "_T"])
713    if out["Torque_FEA_Nm"].isna().any():
714        print("Warning: some operating points have no FEA torque match.")
715    return out

718# ============================================================================
719# THE WHOLE STAGE
720# ============================================================================
721def build_flux_map(path, turns_ratio, stack_factor, pole_pairs, rotor_mode="from_flux",
722                   inductance_method="vectorised", fea_torque_csv=None, verbose=True,
723                   **rotor_kwargs):
724    """Turn one winding table into a flux map (steps 1-7, then torque).
725
726    Parameters
727    ----------
728    path : str or pathlib.Path
729        Winding-table CSV in the Maxwell export format.
730    turns_ratio : float
731        Real turns / model turns (Cobalt 33/2, Zenodo 1).
732    stack_factor : float
733        2D-to-3D correction for field quantities (Cobalt 0.9, Zenodo 1).
734    pole_pairs : int
735        Number of pole pairs p (Cobalt 5, Zenodo 8).
736    rotor_mode : {"from_flux", "fixed", "sweep"}, optional
737        How the rotor angle is found; see rotor_angle(). Default "from_flux".
738    inductance_method : {"vectorised", "loop"}, optional
739        How the inductance matrix is Park-transformed; see dq_per_row().
740        Default "vectorised".
741    fea_torque_csv : str or pathlib.Path, optional
742        Operating-point file with the FEA's own torque (Zenodo only). Adds
743        the column Torque_FEA_Nm. Default None.
744    verbose : bool, optional
745        Print the rotor sweep, psi_pm and the inductance comparison. Default
746        True.
747    **rotor_kwargs
748        Further options passed to rotor_angle().
749
750    Returns
751    -------
752    flux_map : pandas.DataFrame
753        One row per FEA operating point. J [A_per_m2] and TimingAdjustment
754        [deg] are the FEA sweep settings; Id and Iq [A] the real-machine dq
755        current (peak); Psi_d, Psi_q, Psi_mag, Psi_pm_eff and Psi_pm [Wb] the
756        flux linkages; Ld_matrix and Lq_matrix [H] Maxwell's matrix,
757        dq-transformed; Ld_inc, Ldq_inc, Lqd_inc and Lq_inc [H] finite
758        differences on the FEA grid; Ld_app and Lq_app [H] the apparent
759        inductances; Saliency = Lq_matrix / Ld_matrix; Torque_Nm the flux
760        formula; Torque_matrix_Nm the original matrix formula (for
761        comparison); Imag [A] and beta [deg] the current magnitude and angle;
762        and Torque_FEA_Nm if fea_torque_csv is given. The cycle-averaged
763        model-turn values (id_raw ... Lqm_raw) are kept too.
764
765    Raises
766    ------
767    FileNotFoundError
768        If the file does not exist.
769    ValueError
770        If the table fails a check in load_winding_table(), rotor_angle(),
771        dq_per_row() or pm_flux().
772
773    Examples
774    --------
775    >>> flux_map = build_flux_map("Input_Data/Cobalt/cobalt_input_data.csv",
776    ...                           turns_ratio=33 / 2, stack_factor=0.9,
777    ...                           pole_pairs=5, verbose=False)
778    >>> len(unique_operating_points(flux_map))
779    71
780    >>> print(f"psi_pm = {flux_map['Psi_pm'].iloc[0] * 1e3:.1f} mWb")
781    psi_pm = 48.2 mWb
782    """
783    raw = load_winding_table(path)                                   # 1
784    data = rotor_angle(raw, rotor_mode, verbose=verbose, **rotor_kwargs)   # 2
785    data = dq_per_row(data, inductance_method)                       # 3
786    m = average_cycles(data)                                         # 4
787    m = scale(m, turns_ratio, stack_factor)                          # 5
788    m, psi_pm = pm_flux(m, verbose)                                  # 6
789    m = grid_inductances(m)                                          # 7
790
791    # Torque: the flux formula is now the main one. preprocess_v3's formula is kept
792    # beside it so the two can be compared (report section 4).
793    m["Torque_Nm"] = torque_from_flux(m["Psi_d"], m["Psi_q"], m["Id"], m["Iq"], pole_pairs)
794    m["Torque_matrix_Nm"] = matrix_torque(m["Psi_pm_eff"], m["Ld_matrix"], m["Lq_matrix"],
795                                          m["Id"], m["Iq"], pole_pairs)
796    m["Psi_pm"] = psi_pm
797    m["Imag"] = np.hypot(m["Id"], m["Iq"])
798    m["beta"] = np.degrees(np.arctan2(-m["Id"], m["Iq"]))
799    if fea_torque_csv is not None:
800        m = attach_fea_torque(m, fea_torque_csv)
801    if verbose:
802        print_diagnostics(m)
803    return m

834def unique_operating_points(m):
835    """Drop repeated physical operating points before fitting a model.
836
837    The FEA sweeps repeat some points: J = 0 is run once per angle, and on a
838    full-circle sweep TimingAdjustment = -180 and +180 are the same angle. A
839    repeat in both the training and test folds would make cross-validation
840    look better than it is, so only the first copy is kept.
841
842    Parameters
843    ----------
844    m : pandas.DataFrame
845        Flux map from build_flux_map().
846
847    Returns
848    -------
849    pts : pandas.DataFrame
850        The unique operating points, re-indexed from 0.
851    """
852    t = ((m[COL_TIMING] + 180.0) % 360.0) - 180.0               # -180 and +180 -> same
853    t = np.where(m[COL_J] == 0, 0.0, t)                         # every J=0 row is one point
854    key = pd.DataFrame({"J": m[COL_J].round(9).to_numpy(), "T": np.round(t, 6)})
855    return m.loc[~key.duplicated().to_numpy()].reset_index(drop=True)

601def grid_inductances(m):
602    """Compute incremental and apparent inductances at the FEA points.
603
604    Incremental: finite differences (np.gradient, 3-point central) on the
605    polar J x TimingAdjustment grid, then the chain rule (a 2x2 Jacobian
606    solve) to get d/dId and d/dIq. They are NaN at J = 0, where the polar
607    grid collapses to a point.
608
609    Apparent: Ld_app = (psi_d - psi_pm_eff) / Id and Lq_app = psi_q / Iq.
610    The 0/0 points are filled with their limits, the incremental values.
611
612    Parameters
613    ----------
614    m : pandas.DataFrame
615        Output of pm_flux().
616
617    Returns
618    -------
619    m : pandas.DataFrame
620        A new DataFrame with Ld_inc, Ldq_inc, Lqd_inc, Lq_inc, Ld_app and
621        Lq_app [H] added, plus Saliency = Lq_matrix / Ld_matrix (the original
622        script's exported saliency).
623    """
624    Jv = np.sort(m[COL_J].unique())
625    Tv = np.sort(m[COL_TIMING].unique())
626
627    def pivot(col):
628        return m.pivot(index=COL_J, columns=COL_TIMING, values=col).loc[Jv, Tv].to_numpy()
629
630    Id_g, Iq_g = pivot("Id"), pivot("Iq")
631    Pd_g, Pq_g = pivot("Psi_d"), pivot("Psi_q")
632
633    # Derivatives along the two grid directions (current magnitude J, angle T)
634    dId_dJ, dId_dT = np.gradient(Id_g)
635    dIq_dJ, dIq_dT = np.gradient(Iq_g)
636    dPd_dJ, dPd_dT = np.gradient(Pd_g)
637    dPq_dJ, dPq_dT = np.gradient(Pq_g)
638
639    Ldd = np.full_like(Id_g, np.nan)   # dPsi_d/dId
640    Ldq = np.full_like(Id_g, np.nan)   # dPsi_d/dIq  (cross-saturation)
641    Lqd = np.full_like(Id_g, np.nan)   # dPsi_q/dId
642    Lqq = np.full_like(Id_g, np.nan)   # dPsi_q/dIq
643    for i in range(Id_g.shape[0]):
644        for j in range(Id_g.shape[1]):
645            # Chain rule: [dpsi/dJ, dpsi/dT] = Jac @ [dpsi/dId, dpsi/dIq]
646            Jac = np.array([[dId_dJ[i, j], dIq_dJ[i, j]],
647                            [dId_dT[i, j], dIq_dT[i, j]]])
648            if abs(np.linalg.det(Jac)) < 1e-12:
649                continue                      # singular at J=0 (grid collapses)
650            inv = np.linalg.inv(Jac)
651            gd = inv @ np.array([dPd_dJ[i, j], dPd_dT[i, j]])
652            gq = inv @ np.array([dPq_dJ[i, j], dPq_dT[i, j]])
653            Ldd[i, j], Ldq[i, j] = gd
654            Lqd[i, j], Lqq[i, j] = gq
655
656    # Back to one row per operating point (the same as preprocess_v3's .stack(), but
657    # without dropping the NaN J=0 rows on older pandas versions)
658    JJ, TT = np.meshgrid(Jv, Tv, indexing="ij")
659    inc = pd.DataFrame({COL_J: JJ.ravel(), COL_TIMING: TT.ravel(),
660                        "Ld_inc": Ldd.ravel(), "Ldq_inc": Ldq.ravel(),
661                        "Lqd_inc": Lqd.ravel(), "Lq_inc": Lqq.ravel()})
662    m = m.merge(inc, on=[COL_J, COL_TIMING], how="left")
663
664    # ---- apparent (secant) inductances ----
665    I_tot = np.hypot(m["Id"], m["Iq"])
666    ok_d = (np.abs(m["Id"]) > 0.02 * I_tot) & (np.abs(m["Id"]) > 0.5)
667    ok_q = (np.abs(m["Iq"]) > 0.02 * I_tot) & (np.abs(m["Iq"]) > 0.5)
668    m["Ld_app"] = np.where(ok_d, (m["Psi_d"] - m["Psi_pm_eff"]) / m["Id"], np.nan)
669    m["Lq_app"] = np.where(ok_q, m["Psi_q"] / m["Iq"], np.nan)
670
671    # Fill undefined 0/0 points with their mathematical limits (the incremental
672    # values), so the grid is complete
673    m["Ld_app"] = m["Ld_app"].fillna(m["Ld_inc"])
674    m["Lq_app"] = m["Lq_app"].fillna(m["Lq_inc"])
675    pure_d = m.loc[m["Ld_inc"].notna() & (np.abs(m["Iq"]) < 0.5), "Ld_inc"]
676    pure_q = m.loc[m["Lq_inc"].notna() & (np.abs(m["Id"]) < 0.5), "Lq_inc"]
677    m["Ld_app"] = m["Ld_app"].fillna(pure_d.iloc[0] if len(pure_d) else np.nan)
678    m["Lq_app"] = m["Lq_app"].fillna(pure_q.iloc[0] if len(pure_q) else np.nan)
679
680    # Saliency from the matrix inductances, as preprocess_v3 exported it
681    m["Saliency"] = m["Lq_matrix"] / m["Ld_matrix"]
682    return m
